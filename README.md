# Logic Meso RP2040 Lite

Welcome to the official repository for the **Logic Meso RP2040 Lite**. This board is designed to provide a reliable, Feather-compatible data logging platform using locally available components.

## 🤝 Attribution & Credits
This project is a hardware remix and follows the Open Source Hardware philosophy:
* **Base Design:** This board is based on the [Adafruit Feather RP2040 Adalogger](https://www.adafruit.com/product/5302) schematic.
* **Credit:** All original circuit logic and "Feather" form-factor standards are credited to **Adafruit Industries**. 
* **Our Changes:** We have modified the PCB layout for local manufacturing and swapped MOSFET components to ensure availability in the Southeast Asian market.

## 📂 Project Structure
* `/Documentation`: High-quality Schematic PDF for educational use.
* `/Firmware`: Example MicroPython and C++ code for Logic Meso.
* `/Images`: Photos and 3D renders of the board.

> **Note:** To protect our local manufacturing process, the raw PCB layout files (Gerbers) are proprietary. We provide the Schematic PDF so the community can learn the "Logic" of the board.
